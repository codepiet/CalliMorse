# CalliMorse
Morseapparat auf Basis eines Calliope Mini

**The Text is in German - Calliope Mini is used in German-speaking countries**

Der **Calliope Mini** ist ein verbreiteter Mikrocontroller im MINT-Bereich der Schulen in Deutschland. Dieser wird vor allem mit der Sprache NEPO im Roberta Lab oder mit makecode programmiert. Eine weitere Sprache für den **Calliope Mini** ist Micropython, von dem es jedoch zwei Alternativen gibt. Es gibt zum einen den calliope.cc/python-Editor, der jedoch ein eingeschränktes Micropython bietet. 

Daher wird hier die micropython-Firmware für den Calliope Mini verwendet, die eine mächtigere API besitzt. Hier ist es zum Beispiel möglich, das Abspielen eines Tons zu starten und später wieder zu beenden. Entwickelt wurde die Software mit TigerJython. Diese Software hat eine Unterstützung für den Calliope Mini an Bord, hier muss man jedoch vorsichtig sein. Die flash-Funktion funktionierte bei mir nicht - die REPL (Read-Eval-Print-Loop) Unterstützung hat jedoch wunderbar funktioniert und damit ging auch der Download der Python-Software auf den Calliope Mini.

Dieses Projekt enthält Sourcecode (eine Python-Datei), 3D-Druckdateien und Anleitung zur Fertigung und Bedienung.
